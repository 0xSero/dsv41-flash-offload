# D130 (2026-10-03): current default, 1x RTX 3090 24 GB + EPYC 7443P + 503 GB DDR4

Changes vs D119/D123 (all in `docker/entrypoint.sh` defaults and `ct/ct_vllm.py`):
- prefix caching on; V4.1's ratio-2 compressor ring is empty at block-aligned hits, so a fresh ring is exact
  (measured: greedy tokens identical, |dlogprob| <= 0.03 at 4k/32k, 1e-5 at 131k)
- steps <= 512 tokens run the CPU-tier + zero-copy split path instead of streaming all 204 GB of cold experts
- elastic VRAM expert cache back (~395 slots): released only before > 512-token steps, rewarmed after 4 decode steps
- 8 DMA staging slots (deeper next-layer prefetch), chunk 8192
- scheduler: decode share 0.25 during long prefills; long-prompt chunks capped at 7168 only while >= 2 requests compete

All numbers: live server, OpenAI API, natural EOS, no max_tokens; unique cache_salt per request (cold prefill).

`bench/soak.py`, `bench/trace_gaps.py`.
